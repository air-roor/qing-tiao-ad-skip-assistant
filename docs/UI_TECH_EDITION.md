# 轻跳 beta.5：石墨黑与冰青色

日期：2026-10-25（Asia/Shanghai）

本版响应用户“科技感、高级、有吸引力”的视觉反馈，替换原薄荷绿设计。实现继续使用 Java / Android View，不增加 UI 框架、网络字体或位图素材依赖。

## 视觉构成

| 角色 | 色值 / 处理 |
| --- | --- |
| 背景 | `#090D14` 石墨黑 |
| 卡片 | `#121A26`，1dp 细描边 |
| 正文 | `#EDF3FA` |
| 次要正文 | `#97A9BC` |
| 主操作 | `#6DE5ED` 冰青色，按钮配深色文字 |
| 选中底色 | `#17313D` |
| 线条 | `#29384A` |
| 提醒 | `#F4C989` |
| 状态面板 | `#16303B → #111C2A → #121824` 渐变 |
| 装置弧线 | 冰青色与 `#818CF8`；只用于装饰 |

首页品牌、状态标题和说明、静态光环、总开关、两项真实计数、模拟测试、运行配置依次排列。等宽字体仅用于数字和装饰标签，中文仍使用系统字体。主要按钮不小于 50dp，导航不小于 48dp，行操作保留整行点击语义。

状态装置使用 Canvas、径向渐变与圆弧绘制。没有定时器、持续旋转或视图自刷新；服务连接变化沿用原来仅在首页前台运行的状态观察。装置在未就绪时降色，文字保留“暂停 / 权限待开启 / 等待连接 / 未选应用”的区别，不用动画伪装运行。

本版本有意固定深色主题；系统浅色和深色配置使用一致的深色资源，包括原生对话框、输入框、状态栏和导航栏。

## 范围与延续

- 应用选择草稿、取消、保存、反馈字段及本机诊断保持原有逻辑。
- 应用列表选中项同时用复选状态与描边表达，不仅依靠背景色。
- 保留 beta.4 横屏紧凑工具栏、可滚动内容和反馈底部操作区；新视觉仍需真机验收。
- 没有修改 SkipService、Rules、反馈收集内容或权限；没有新增速度、成功率、节省时间或收费承诺。
- 桌面图标与首页闪电、光环统一，均为项目独立绘制图形。

## 预览与证据边界

[三页设计示意图](ui-tech-preview.png) 由 `scripts/render-ui-preview.py` 使用 Pillow 绘制，配色与结构对应原生实现，但不是 Android 渲染截图。图中示例图标、包名、计数用于设计说明，不读取手机数据，也不证明真机排版或跳过效果。

用户选择“稍后连接，先完成 APK”，因此本轮没有连接或安装到手机。小屏、横屏、大字体、键盘与系统对话框仍需在 beta.5 真机安装后检查。历史 beta.3 / beta.4 的设备结果见 [设备测试记录](DEVICE_TEST_2026-10-25.md)，不能直接算作 beta.5 的验收。

使用了已安装的 ui-ux-pro-max 与 mobile-android-design 技能。首次设计系统查询偏向 Apple 玻璃和营销叙事，不适合本项目；随后通过 `dark oled utility --domain style` 得到 Dark Mode (OLED) 结果，参考其深色、高对比和克制光效原则。未采用网页滚动叙事、Apple 玻璃或网络字体。最终视觉为本项目独立实现。
