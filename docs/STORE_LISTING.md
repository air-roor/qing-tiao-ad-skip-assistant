# 应用商店上架文案草案

更新日期：2026-10-24

## 名称

轻跳 · 开屏广告跳过助手

## 简短说明

本地识别你所选应用中的可读跳过按钮，无法识别时保持原样。

## 完整说明

轻跳是一款无需 Root 的 Android 开屏广告跳过助手。你选择要处理的应用后，轻跳会在应用启动后的短时间内，通过系统无障碍服务识别明确的“跳过广告”“跳过 2”“Skip ad”等可读按钮并发送点击。

主要特点：

- 只处理你主动选择的应用；
- 识别和判断完全在设备本机完成；
- 应用本身没有网络、存储、位置、相机或麦克风权限；
- 点击前重新读取实时控件，减少界面切换造成的误点；
- 锁屏、系统敏感应用、输入框、密码和身份验证页面停止自动点击；
- 提供模拟广告测试、最近诊断和用户主动导出的诊断文字；
- 提供结构化公测反馈，用户预览内容后再决定复制、系统分享或提交公开 GitHub Issue；
- 无法读取按钮、倒计时未结束或规则不确定时保持页面原样。

轻跳依赖目标应用通过 Android 无障碍框架公开的控件信息。图片、自绘控件、部分 WebView、强制倒计时和没有跳过入口的广告可能无法处理。轻跳不能保证兼容所有应用或所有广告。

## 无障碍服务显著披露

建议在录制审核视频和提交商店时使用与应用内一致的说明：

> 轻跳使用无障碍服务读取你所选应用公开的界面控件文字、控件 ID 和位置，用于识别广告的跳过或关闭按钮，并代表你发送点击或短触摸手势。识别在本机完成，不联网、不截图、不保存页面正文或控件文字。你可以随时关闭总开关、取消应用选择，或在系统设置撤销权限。

轻跳不是帮助残障用户使用设备的无障碍工具，因此不得把 `isAccessibilityTool` 声明为 true。

## Google Play 权限声明回答草案

核心功能：在用户明确选择的应用内，依据固定、可解释的文字、控件 ID、时间和安全规则，自动点击开屏广告的跳过按钮。该用途范围狭窄，用户可以逐应用启用或停用。

自动化性质：确定性的规则自动化。轻跳不会自主规划任务，不会跨应用完成交易，不会点击支付、授权、登录或普通关闭按钮。

访问的数据：所选前台应用通过无障碍框架公开的控件文字、内容描述、资源 ID、位置、可点击状态和窗口事件。

数据处理：只在本机内存中用于实时判断，不保存页面正文或控件文字，不上传，不与第三方共享。

审核视频建议展示：打开应用 → 阅读独立披露 → 主动同意 → 进入系统设置开启服务 → 选择模拟应用 → 自动跳过模拟广告 → 普通按钮页保持不动 → 关闭总开关后停止处理。

## 截图建议

4. 锁屏/输入/密码页面保护说明。
5. 最近诊断与隐私化导出。
6. 公测反馈表单与发送前预览。
