# 轻跳隐私说明

生效日期：2026-10-24

轻跳是一款在 Android 设备本机运行的开屏广告跳过助手。本说明适用于 `cn.local.adskip` 0.3.0-beta.3。

## 无障碍服务读取什么

只有在你手动开启系统无障碍服务、打开轻跳总开关，并选择目标应用后，轻跳才会读取该应用通过 Android 无障碍框架公开的：

- 当前前台应用包名；
- 可见控件的文字、内容描述、资源 ID、位置和可点击状态；
- 窗口变化事件。

轻跳用这些信息判断是否存在符合固定规则的广告跳过或关闭按钮，并代表你发送点击或短触摸手势。轻跳不是残障辅助工具，服务配置明确声明 `isAccessibilityTool=false`。

## 不收集什么

- 不申请网络权限，不会把界面内容发送到服务器；
- 不截图、不录屏、不使用 OCR；
- 不读取或保存密码输入框内容；
- 不保存页面正文或无障碍控件文字；
- 不申请通讯录、短信、相机、麦克风、位置、存储或悬浮窗权限；
- 不集成广告 SDK、统计 SDK或第三方追踪 SDK。

## 本机保存的数据

轻跳在应用私有存储中保存：

- 总开关和规则开关；
- 你选择的应用包名；
- 系统接受的点击请求次数；
- 最近一次处理的应用包名、时间、命中路径和耗时；
- 最近一次诊断的应用包名、时间和分类结果。
- 用户生成反馈预览的次数，以及最近反馈编号、问题类型和时间。持久配置中不保存反馈正文。
- 应用选择草稿、当前页面、搜索词及反馈草稿会在页面内存和 Android 临时页面恢复状态中保留，用于切换页签或旋转屏幕后继续编辑；反馈正文不写入应用持久配置文件，也不会自动上传。

卸载轻跳后，这些应用私有数据会由 Android 系统清除。当前版本不使用 Android 云备份。

## 主动分享与诊断导出

在“我的 → 填写公测反馈”中，用户可以选择问题类型、填写相关应用和描述，并在本机生成一个随机反馈编号。用户可以决定是否把设备型号、系统版本、最后处理的应用包名和规则结果附在反馈中。生成后会先显示完整可编辑预览，不会自动上传。

“分享轻跳”“导出诊断”和反馈中的“系统分享”会打开 Android 系统分享页。轻跳不会自动选择接收方或自动发送。复制反馈会把用户确认的文字写入系统剪贴板，其他具有剪贴板访问能力的应用可能读取该内容，请在使用后按需清除。

“提交到 GitHub”会调用浏览器并把用户确认的标题和正文填入 GitHub Issue 页面。GitHub Issue 提交后通常公开可见，并受 GitHub 的账号和隐私规则约束；用户应再次检查后手动提交。“查看隐私说明”等链接同样由浏览器打开。轻跳自身没有网络权限。

当前免费公测版没有轻跳账号、登录、应用内支付或后台反馈服务器。未来加入账号和永久权益前，会更新本说明并单独取得必要同意；不会把本次公测反馈自动转换成账号资料。

## 安全限制

轻跳在锁屏、系统敏感应用，以及检测到输入框、密码或身份验证内容的页面停止自动点击。规则仍可能漏识别或误判，用户可以关闭总开关、取消某个应用，或在系统设置撤销无障碍权限。
