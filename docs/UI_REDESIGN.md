# 轻跳 0.3.0-beta.3 界面重设计

日期：2026-10-25（Asia/Shanghai）

## 目标与设计取舍

把原先一个长页面中的大标题、默认灰色按钮和大量说明，整理成可直接操作的三页原生应用。当前项目使用 Java 和 Android View，继续使用无 Gradle 构建，不引入 Compose 依赖、网络字体或第三方图片资源。

- 首页：品牌、真实服务状态、总开关、点击请求计数、已选应用数，以及授权、管理应用、模拟测试入口。
- 应用：本机应用图标、名称和包名，名称/包名搜索，全部/已选择筛选，清空草稿，固定的取消和保存栏。
- 我的：免费公测反馈、明确关闭广告开关、模拟测试、服务保活帮助、本机诊断、分享与隐私入口。
- 反馈：独立可滚动表单，六种问题分类、字段标签、诊断选择和预览。
- 预览：可编辑内容、复制、系统分享和公开 GitHub 提交。
- 模拟测试页同步采用相同视觉组件。

## 视觉规范

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | `#F5F7F5` | `#111A18` |
| 卡片 | `#FFFFFF` | `#1B2723` |
| 正文 | `#182D27` | `#EDF5EF` |
| 次要正文 | `#5C6E65` | `#AEBFB5` |
| 主色 | `#256747` | `#8AD6B0` |
| 辅助底色 | `#E7F0E9` | `#293E33` |
| 主状态卡 | `#E0EFDF` | `#213E30` |
| 主状态卡文字 | `#214F35` | `#DEF1E1` |

间距以 4/8dp 为基础，手机左右留白 20dp，正文 13–15sp，页面标题 28sp，状态标题 24sp，辅助文字 11–12sp。正文随系统字号缩放；卡片高度由内容决定。主要按钮最小高度 50dp，导航和整行入口至少 48dp。所有图标为独立绘制的同一套线性图形，无 Emoji，无外部图片和字体下载。

首页与表单内容最大宽度 640dp。应用页在低于 500dp 高度时采用紧凑标题。状态栏、导航栏、刘海和输入法区域通过 WindowInsets 处理。系统深色模式使用独立语义配色和原生深色对话框。没有持续循环动画，减少动态效果不影响可用性。

## 交互与状态

- 首页区分总开关、系统授权和服务实际连接；只在服务已连接且有选中应用时显示守候状态。
- 首页可见时检查服务连接变化，离开前台后停止刷新。
- 应用名单在后台线程加载，ListView 复用行视图，不把应用清单发往网络。
- 勾选、清空只改草稿，保存同步提交；取消恢复已保存名单。
- 页签切换保留草稿；退出有未保存修改时提示保存、放弃或继续编辑。
- 屏幕旋转保存当前页、搜索、名单草稿、分类、诊断选择和反馈文字。
- 反馈可见字段有限长限制；预览由用户确认后才允许复制或发送。
- 点击量始终标为“点击请求”，不虚构成功率、节省时间或日统计。

## 验证边界

本轮最终 APK 需经过 48 项规则与反馈格式检查、zipalign、签名及 aapt 版本/权限验证。UI 构建通过不能替代触摸、键盘、旋转、系统深色模式和大字号验收。

beta.3 首次发布时手机未连接，因此当时没有真机验收。随后用户重新连接 Pura 70，完成 beta.3 的测试并发现横屏应用列表高度问题，已在 beta.4 修复；反馈预览也改成底部固定操作区。更新结果见 [2026-10-25 真机记录](DEVICE_TEST_2026-10-25.md)。
